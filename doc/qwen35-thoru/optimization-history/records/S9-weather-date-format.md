# S9 — 保留预报结构并修复上海跨日时间处理

天气压缩现在保留原有 `forecasts` 数组结构，仅保留用户所问次日的一个预报条目。逐个处理所有天气工具结果，避免在 Agent 重复查询时只压缩第一个、后续结果仍混有当天与其他日期。缺少目标日期或天气字段时保留原结果；内容已规范化时保持幂等。

时间先转换为上海日期再按天归一化，保留 `+08:00[Asia/Shanghai]` 标识；压缩目标日期也按同一时区计算。原来的 UTC 日期加一天，在上海午夜后会少算一天。按天归一化用于本次按日期查询的天气 benchmark，不代表精确时刻。

验证：11 项 Python CPU 回归通过，新增重复天气结果、幂等及 `2026-11-03T16:24Z` 在上海已是 11 月 4 日、次日应为 11 月 5 日的检查。该提交不修改模型算子，端到端变化必须归入 Agent 输入/日期处理，不能说成 GPU kernel 加速。该提交实际10/10通过，中位数1.774990 s、P90 1.964870 s。
